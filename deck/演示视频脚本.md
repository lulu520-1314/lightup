# 90 秒演示视频 · 脚本与录制指南

> 初赛提交需要「一段创意讲解或实际使用的演示视频」。下面是逐秒分镜，照做即可。
> 目标：让评委在 90 秒内经历 **"困惑 → 惊喜 → 认同"** 三次情绪转折。

---

## 一、录制前准备（10 分钟）

| 项 | 做法 |
|---|---|
| 录屏 | Windows 自带 `Win + G`，或 OBS（免费）。**只录 Chrome 窗口**，不要录整屏。 |
| 浏览器 | Chrome，窗口最大化，按 `F11` 全屏，关掉书签栏（`Ctrl+Shift+B`）。 |
| 启动 | 双击 `app/启动Demo.bat`，等浏览器打开 `http://127.0.0.1:8765` |
| 摄像头 | 三种画面来源任选：**摄像头**（实时）／**上传图片**（左下按钮或按 `U`，也可直接把图拖进框）／**示例照片**。不想露脸就用后两种，效果一样 |
| 光线 | 用相机模式时，面朝窗户或台灯，**不要让光在身后** |
| 声音 | 声化是本片核心，务必**录系统声音**（OBS 里勾选"桌面音频"），否则观众听不到旋律 |
| 画幅 | 1920×1080，30fps 即可 |

> 建议：先完整走一遍流程（读色 → 记住 → 验妆 → 诊肤色），确认每一步都有声音和播报，再正式录。

## 三、旁白全文（约 190 字，语速稍慢刚好 88 秒）

> 视障者买口红，只能这样问："这个红，是哪个红？"
>
> 我们把这个问题，交给了一段旋律。
>
> 色相被压成五声音阶的十个音位，冷暖决定和弦。同一支口红，永远是同一段旋律。
>
> 它会告诉你：这是什么色、偏冷还是偏暖、和标准色卡差多少。
>
> 记住目标色，涂完再测一次——它会告诉你，还差多少。
>
> 它还会告诉你，什么颜色适合你。不是"显白"，是可以计算的 ITA 肤色角。
>
> 全程可以只用键盘，语音和字幕双通道，大字、高对比都支持。
>
> 所有计算都在本机，画面不出设备，一台普通笔记本就够。
>
> 我们做的不是一款 App，是让颜色可以被听见的翻译标准。

---

## 四、三个必须做对的细节

1. **一定要让评委听到旋律。** 这是全片唯一的"哇点"。录屏时检查系统声音是否录入（录完先自己看一遍，如果没有声音，重录）。
2. **不要念技术名词。** 旁白里没有一个 "MediaPipe"、"CIEDE2000"；技术留在 PPT 里，视频只讲体验。
3. **结尾停 2 秒。** "让美，不依赖眼睛" 出字后不要立刻切走，留白会让它落地。

## 附：评委会问的问题（提前想好）

| 问题 | 参考回答 |
|---|---|
| 视障者真的需要口红色号吗？ | 需要。美妆是社交与就业的一部分，视障女性同样有打扮自己的需求；她们现在的做法是"问别人"，我们要拿走这个依赖。 |
| 声音怎么学？会不会记不住？ | 需要 3–5 次训练，我们把它设计成"可训练"而不是"天生就会"：同一色系永远是同一段旋律，练的是"分辨"，不是"背诵"。 |
| 为什么不用大模型描述颜色？ | 描述解决不了"记住"。大模型每次说的话都不一样，而旋律每次完全一致——可复现，才能被信任。 |
| 和 Be My Eyes、Seeing AI 有什么不同？ | 它们在"描述世界"，我们在"支持决策"：不是告诉你面前有什么，而是告诉你"这支适不适合你、你涂对没有"。 |
| 商业上怎么成立？ | 先作为专柜无障碍服务（品牌责任），再进入电商详情页（降低退货），最后沉淀为行业色号标准。 |
